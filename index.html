● Message Passing Interface

Параллельдік есептеулерді MPI арқылы меңгеріңіз

Жоғары өнімді есептеулердің негізгі стандарты: теория, 100+ тапсырма, код мысалдары және PT4 тексеру ортасы — бір орталықта.

БастауПрактика
hello.c
#include "mpi.h"
int main(int argc, char *argv[]) {
  MPI_Init(&argc, &argv);
  int rank, size;
  MPI_Comm_rank(MPI_COMM_WORLD, &rank);
  MPI_Comm_size(MPI_COMM_WORLD, &size);
  printf("Process %d of %d\n", rank, size);
  MPI_Finalize();
  return 0;
}

MPI жылдам бастау

Бірнеше минутта алғашқы бағдарламаңызды іске қосыңыз

mpi_hello.c
#include "mpi.h"
#include <stdio.h>

int main(int argc, char *argv[]) {
  int rank, size;
  MPI_Init(&argc, &argv);
  MPI_Comm_rank(MPI_COMM_WORLD, &rank);
  MPI_Comm_size(MPI_COMM_WORLD, &size);
  printf("Сәлем! Мен %d процесім, барлығы %d\n",
         rank, size);
  MPI_Finalize();
  return 0;
}
terminal
$ mpicc mpi_hello.c -o hello
$ mpirun -np 4 ./hello
// «Іске қосу» батырмасын басыңыз

FAQ

MPI дегеніміз не?

Процестер арасында хабар алмасуға арналған параллель бағдарламалау стандарты.

MPI-ды қалай орнатамын?

Windows-та MS-MPI, Linux-та OpenMPI немесе MPICH. Тексеру: mpicc --version.

PT4 дегеніміз не?

MPI тапсырмаларын орындап, нәтижесін тексеруге арналған оқу ортасы.

Прогресс қайда сақталады?

Тапсырма белгілері осы браузерде сақталады және басқа құрылғыға берілмейді.
